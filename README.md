# Apple Nigeria Homepage Clone

A static, front-end recreation of the Apple Nigeria homepage, built with HTML and CSS.

## Live demo

[View the live site](https://apple-clon-eta.vercel.app/)

## Features

- Apple-inspired navigation with product and support dropdowns
- Homepage feature sections for iPhone, Mac, and iPad
- Product imagery and icons stored in the `images/` directory

## Run locally

This project does not require a build step or package installation. Open `index.html` in a browser, or serve the project directory with any static web server.

## Technologies

- HTML
- CSS
